# Artifact Photos

Real photos of the objects, shown inside the bedroom and the exhibit
plaques with the museum's warm night-room treatment (slight tilt, deep
shadow, lamp-lit color grade).

## Conventions

- Filename = artifact id + `.jpg`: `laptop.jpg`, `notebook.jpg`,
  `certificates.jpg`, `broken-code.jpg`, `chessboard.jpg`,
  `gap-year.jpg`, `mobile.jpg`, `drawer-letter.jpg`, `bracelet.jpg`
- Square-ish 4:3 or 1:1, 800–1200 px on the long edge is plenty
- Any file missing → the CSS glyph illustration shows instead

Photos are lazy-loaded and never block first paint.
